# Backend development

- Candidate backend: NestJS, TypeScript, REST `/api/v1`, modular monolith.
- Read specs, ADRs, API conventions, security guidance and module instructions.
- Use clear modules, service boundaries, DTO validation, guards and dependency injection.
- Authenticate requests and independently authorize resource access. Couple membership is not optional authorization.
- Define predictable errors, pagination, idempotency and transactions where appropriate.
- Document API contracts and use OpenAPI where established.
- Test behavior with unit tests and integration tests, including real PostgreSQL where DB semantics matter.
- Avoid unnecessary service decomposition, queues and dependencies.
