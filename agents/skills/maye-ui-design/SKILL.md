# Maye UI design skill

Maye should feel like a cozy, intimate scrapbook—not a generic dashboard, sterile SaaS product, or social-media clone.

## Visual direction
- Warm cream, blush, muted rose, cocoa, and restrained soft-lavender accents.
- Paper textures, subtle shadows, scrapbook layering, polaroid-like photo frames, washi tape, stamps, tiny doodles, stickers and heart/flower motifs used sparingly.
- Rounded, readable typography with an optional restrained handwritten accent.
- Playful details and subtle motion; content remains the focus.

## Principles
- Mobile-first, accessible, readable, touch-friendly, and consistent.
- Establish design tokens for color, typography, spacing, radius, shadows, motion and icon conventions.
- Custom cohesive components are encouraged (e.g., memory/photo frames, album/letter/question/bucket-list cards, reactions, mood selector, notification item) when useful; avoid abstraction for its own sake.
- Include loading, error, empty, disabled and interaction states.
- Maintain contrast and reduced-motion/accessibility needs.

## Avoid
- Sterile white dashboard aesthetics or corporate blue defaults.
- Heavy glassmorphism, excessive gradients, repeated generic card grids.
- Over-decoration, unreadable handwritten fonts, inconsistent tokens or aggressive animations.
- Treating cute styling as an excuse to sacrifice usability.

Use references in the UI design spec when one is established; do not invent a complete design system in a single feature task.
