# Mobile development

- Candidate platform: Expo, React Native, TypeScript and Expo Router; validate/record architecture decisions.
- Read feature specs, UI skill and app-specific instructions before work.
- Prefer accessible, responsive, maintainable native-feeling patterns and small components with cohesive responsibilities.
- Use TanStack Query for server state and Zustand only for suitable client state.
- Use React Hook Form and the agreed validation strategy for forms.
- Store sensitive client tokens/secrets in appropriate secure storage; never ship backend credentials in the app.
- Cover user-visible behavior, loading/error/empty states, accessibility and meaningful interactions in tests.
- Avoid unnecessary libraries, custom abstractions and premature optimization.
