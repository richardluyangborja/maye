# Agent guidance and skills

`AGENTS.md` files provide repository-specific instructions. Skills are reusable, focused guidance for a task/workflow.

## Skills
- `specification-workflow`: discovery, feature specs, acceptance criteria and slicing.
- `architecture-decisions`: create and review ADRs.
- `tdd-workflow`: RED → GREEN → REFACTOR and verification.
- `git-workflow`: branch, commit, review, merge, cleanup.
- `mobile-development`: Expo / React Native implementation guidance.
- `backend-development`: NestJS API implementation guidance.
- `database-design`: PostgreSQL and Prisma guidance.
- `security`: privacy, authorization, and threat-aware development.
- `media-storage`: secure upload, access and lifecycle.
- `maye-ui-design`: product identity, accessibility and UI conventions.

Use only the skill(s) relevant to the current task. Skills are guidance, not substitutes for approved specs, decisions, or tests.
